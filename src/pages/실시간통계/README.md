# 비즈팅 실시간 통계리포트

저장소에서 `npm run dev` 실행 후 `/biztinginterest/#/real-time-statistics`를 엽니다. 일간통계 주소는 `/biztinginterest/#/real-time-statistics/daily`이고 지역 통계는 `/biztinginterest/#/real-time-statistics/residence`에서 봅니다.

미리보기 인증번호는 `246810`입니다. 연령·성별과 지역 통계는 각각 첨부받은 `list` 형식을 사용합니다. 캠페인 정보, 읽음 건수, 일간 분포는 예시입니다. 성별 코드는 `1`을 남성, `2`를 여성으로 표시합니다.

## 운영 API 연결

Vite 환경변수 `VITE_BIZTING_REPORT_API`에 API의 기본 주소를 지정합니다. 두 응답 모두 같은 리포트 형식을 반환합니다.

| 요청 | 계약 |
| --- | --- |
| `POST /verify` | JSON 본문 `{"code":"246810"}` 형식으로 6자리 인증번호를 검증하고, 인증된 세션과 리포트를 반환합니다. |
| `GET /report` | 인증된 세션의 동일 캠페인 리포트를 반환합니다. 집계 기간 내 열려 있는 실시간·지역 통계 화면은 60초마다 갱신하고, 일간 화면은 다음 집계 시각에 다시 요청합니다. |

인증번호의 유효 기간과 시도 제한은 서버에서 관리합니다. 세션은 자격 증명을 포함한 요청으로 확인합니다. 인증 실패는 401 또는 403, 기간 만료는 410, 요청 제한은 429, 리포트 없음은 404로 응답합니다. 갱신 요청의 401 또는 403은 세션 만료로 표시합니다.

- `campaignName`, `sendDate`(한국 시간 기준 `YYYY-MM-DD`), `sendType`, `updatedAt`(시간대를 포함한 ISO 8601 타임스탬프)은 필수입니다.
- `summary`는 `deliveredCount`, `readCount`, `reactionCount`를 포함합니다. 발송 성공 수와 반응 수가 없으면 `list`의 `totSuccessCnt`, `totReactCnt` 합계를 사용합니다. 제공되지 않은 읽음 수는 대시로 표시합니다.
- `daily`는 `{ date, readCount, reactionCount }` 배열입니다. `date`는 발송 당일부터 7일간의 실제 성과 발생일입니다. 날짜별 건수에는 그날 새로 발생한 건을 포함합니다. 일간 화면에서는 성과일 다음 날 오전 4시 30분(한국시간)부터 해당 성과를 표시합니다. 서버는 집계가 끝난 날의 0건과 아직 집계되지 않은 날의 누락을 구분합니다.
- `list`는 첨부와 같은 형식입니다. 연령·성별 수신자 비율은 분류된 발송 성공 건을 기준으로 계산합니다.
- `areaStats`는 첨부와 같은 `{ list: [...] }` 형식입니다. 지역별 반응률은 `totReactRatio`, 수신자 비율은 각 행의 `totSuccessCnt`를 지역 통계에 포함된 전체 발송 성공 수로 나눠 표시합니다.

지역 통계 지도는 자체 제작한 17개 시·도 개략도를 사용합니다. 시·도 도형과 막대 위치는 로컬에 저장하고, 비율은 리포트 데이터로 계산합니다.
