# 비즈팅 실시간 통계리포트 v1.1

미리보기 주소는 `/biztinginterest/#/real-time-statistics-v1.1`입니다.

인증번호는 `246810` 하나이며 기본 화면은 캠페인 3건이며 첫 캠페인 상세가 바로 열리고 상단 드롭다운으로 바꿉니다. 다른 상태는 아래 주소로 확인합니다.

| 상태 | 미리보기 주소 뒤에 붙이기 |
|---|---|
| 캠페인 1건 | `?preview=single` |
| 최종 결과 | `?preview=final` |
| 열람 만료 | `/expired` |

알림톡은 계정과 발송일 기준 하루 1회 보내고, 링크에는 그날 캠페인만 보여줍니다. 링크는 발송일 + 10일까지 사용합니다. 인증, 만료, 입력 제한은 화면만 구현했으며 실제 처리는 서버 몫입니다. 지역, 연령·성별은 발송 후 96시간 동안만 수집하며 예시 데이터는 캠페인끼리 같습니다.

발송 시각, 목표 건수, RCS 발송 성공 건수, 중복을 제외한 인원은 1.1 목업의 예시값입니다. 날짜와 시각은 한국시간으로 표시합니다. 새로고침 간격은 동일한 브라우저에서 5분입니다.

예외 테스트는 저장소 루트에서 `node --test "src/pages/실시간통계-v1.1/report.test.mjs"`로 실행합니다.
